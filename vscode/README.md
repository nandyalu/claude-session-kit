# Claude usage bar

This VS Code extension shows the token, prompt cache, cost and graft figures of every live Claude Code session on the machine. It is one part of the [Claude session kit](https://github.com/nandyalu/claude-session-kit). The kit's plugin ships the hook that writes the figures, and the kit's README says how to install both parts.

- **The status bar item** shows one session: the newest session that runs inside a folder of this window, or the newest session on the machine when none does. It shows the context size, the cache hit ratio of the last request, the minutes until the cache expires, the tokens graft saved, and the input cost. Each figure follows an icon in place of a word: a pulse for the context, a database for the cache hit ratio, a flame for the minutes until the cache expires, a crossed circle when the cache is cold, graft's own seedling 🌱 for the tokens graft saved, and windows for the count of live sessions when there is more than one. The hover's table headers carry the same icons. The item turns to the warning color at `claudeUsageBar.warnTokens`, 500,000 by default, and to the error color at `claudeUsageBar.alertTokens`, 750,000 by default.
- **The hover** lists every live session on the machine in one table. The sessions of this window come first, with their folder in bold.
- **The details pane** opens on a click, or with the command *Claude usage: show sessions*. It shows one card per live session, with a context meter, tiles for the cache, the cost, graft and the request counts, and a table with the rest.
- **At each line** the extension shows one notification for the session with the three steps that move the work to a fresh session: run `/kit:handoff`, then `/clear`, then say "continue from handoff <topic>".
